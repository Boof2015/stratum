Connecting from Docker or another machine

In Docker, localhost points to Sidecar’s container. Use Navidrome’s container name or its network address instead.

This checks for Navidrome. Listeners sign in with their own Navidrome accounts.

Connection details

Direct connections verify Sidecar’s identity key. A reverse proxy uses its HTTPS certificate and forwards the connection to Sidecar.

Saving an address does not test whether a listener can reach it. The first address is the primary one.

      Discovery

      Sidecar adds a Stratum entry to Navidrome’s internet radio list.

      Compatible apps use it to find Sidecar automatically, so listeners don’t need to enter another server address.

      Other apps may show this entry as a radio station, but it won’t play audio.

      Let compatible apps find Sidecar through Navidrome.

      How discovery works

      Publishing adds a Stratum entry to Navidrome’s internet radio list. Other apps may display it as a radio station. With manual setup, listeners enter a Sidecar address themselves.

      Used once for this change. Never saved.

      How these limits work

      Automatic chooses a conservative conversion limit for this machine. Cached audio does not use a conversion slot.

      Working storage is separate from the retained cache. The lighter bar shows reserved capacity, including space not yet used. Lowering limits lets current work finish; new work waits or retries when capacity is full.
